# Story: Flux Knowledge Manager & Bidirectional Links

- **Status**: Draft
- **Goal**: Unified knowledge manager that tracks saved artifacts, distillations, and concept timelines with bidirectional linking.

## Acceptance Criteria
1. Saved artifacts list shows date, tags, linked concepts.
2. Concepts point to best explanations/distillations (and vice versa).
3. Timeline view shows evolution of concept clusters across sessions.
4. Search feature across all saved distillations.
5. Zettelkasten entries integrate with concept graph highlights.
